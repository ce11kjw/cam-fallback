原理：MTK 相机 HAL 在任一 sensor 探测失败时会空指针崩溃 (createDeviceMap / getSensorId)， 导致所有摄像头不可用。本模块把失效的 sensor 从 HAL 设备表剔除， 让剩余完好的摄像头正常工作。
